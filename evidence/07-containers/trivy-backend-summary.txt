Image composition observations
==============================

The Trivy report enumerates many artifacts under:

/root/.gradle/caches/...

This indicates that the runtime image contains Gradle cache/build dependencies in addition to the application artifact. This increases image size, attack surface and the number of vulnerable components carried into runtime.

Trivy also reported 2 Dockerfile misconfiguration findings for src/Dockerfile. These should be considered together with the independent Semgrep finding that the Dockerfile does not define a non-root USER.

Interpretation
==============

FINDING — the backend image is based on an outdated Debian 10.8 userspace and contains a large number of HIGH/CRITICAL vulnerability findings. It also includes build-time Gradle cache artifacts that should not be present in a minimal runtime image.

Recommended remediation:
1. Rebuild from an actively supported, minimal base image.
2. Use a multi-stage Docker build and copy only the runtime artifact(s) into the final image.
3. Remove Gradle caches/build toolchain from the runtime image.
4. Run as an explicit non-root user.
5. Upgrade application dependencies and OS packages with known HIGH/CRITICAL advisories.
6. Re-scan the rebuilt immutable image and triage remaining runtime-reachable findings.
