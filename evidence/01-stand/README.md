# Доказательства к пункту 1

Снимок состояния локального тестового стенда от 7 августа 2026 года.

Файлы:

- `docker-ps.txt` — список запущенных контейнеров и опубликованных портов;
- `docker-inspect-frontend.json` — санитаризированная проекция `docker inspect necommerce-frontend-1`;
- `docker-inspect-backend.json` — санитаризированная проекция `docker inspect necommerce-backend-1`;
- `docker-image-inspect.json` — идентичность образов и их `Config.Env` из `docker image inspect`;
- `curl.txt` — команды HTTP-проверки и полученные коды ответа.

Проекции `docker inspect` содержат поля, необходимые для идентификации и воспроизведения стенда: ID контейнера и образа, процесс, состояние, порты, ограничения, тома, сеть и Compose labels. Не относящиеся к проверке внутренние поля исключены. В `Config.Env` образов обнаружены только стандартные переменные Java и nginx; это не исключает секреты в истории сборки или файлах слоёв. Секреты, пароли, токены и журналы контейнеров в каталог не включены.
